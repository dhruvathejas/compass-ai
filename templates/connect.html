Connect to your main PC

Your main PC runs Compass AI and keeps your accounts, chats and projects. This device just opens it. Enter the address of the main PC, and Compass will check it before you sign in.

Last host you used:

The address on the main PC's screen when it starts, for example 192.168.1.20:5000, or a tunnel link like https://your-name.trycloudflare.com.

Where do I find the address?
  1. At home, same Wi-Fi: on the main PC stop Compass AI and start it with python app.py --lan. It prints “Other devices on your network:” followed by an address such as http://192.168.1.20:5000. Enter that here. (Plain http on a trusted network only.)
  2. Away from home: start a tunnel on the main PC, for example cloudflared tunnel --url localhost:5000, and enter the https://… link it prints.
  3. localhost or 127.0.0.1 never works here. On a phone or another computer those words mean this device, not the main PC.
It says it can't reach the main PC
  • Is Compass AI running on the main PC (python app.py), and is the main PC awake?
  • Is this device on the same network, or are you using the tunnel link?
  • For a network address, the host must be started with --lan, and Windows Firewall may ask you to allow Python on private networks.
  • This page is on https but the address is plain http? Browsers block that. Open this page over http too, or use the tunnel's https link.
  • Tunnel links change each time cloudflared restarts. Copy the new one.
