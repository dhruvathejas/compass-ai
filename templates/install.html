Install Compass AI

Compass AI runs from its source folder with Python. There is no packaged installer or download yet, so these are the real steps. They take about five minutes.

Your computer

  1. Check what you need

    • Python 3.10 or newer. Check with: {{ cmd("py --version") }} {{ cmd("python3 --version") }} Missing? Get it from python.org and tick “Add Python to PATH”. Missing? Get it from python.org or your package manager.
    • Ollama, installed separately from ollama.com, with at least one model pulled (for example ollama pull llama3.2). Compass AI only talks to it; it never installs, starts or replaces Ollama or your models.
    • Git, to download the code (or use a folder or zip you were given).
    • Optional: VS Code with its code command, for the Code button.

  2. Get Compass AI

    {{ cmd("git clone " ~ repo_url) }} {{ cmd("cd compass-ai") }}

    Got a folder or zip instead? Unpack it and open a terminal inside it.

  3. Install its one dependency

    {{ cmd("py -m pip install -r requirements.txt") }} {{ cmd("python3 -m pip install -r requirements.txt") }}

  4. Start it

    {{ cmd("py app.py") }} {{ cmd("python3 app.py") }}

    Leave that window open while you use Compass AI. It listens only on this computer until you choose otherwise.

  5. Create your account

    On that same computer, open http://localhost:5000. The first account you create becomes the owner of that Compass AI. Then authorize the device when asked.

Already have a Compass AI somewhere?

You don't need to install anything on this device. Connect it to the main PC instead.
